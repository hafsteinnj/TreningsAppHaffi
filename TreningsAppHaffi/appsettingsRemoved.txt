Appsettings were removed from git when i came across the plain text input of usernames, passwords and server adresses etc.
There are more nuanced solutions. But this was the quickest brute force way to make sure it doesn't just get dumped 'out there' for some scraper to pass by.

//funnet ut at jeg kanskje har overreagert da jeg fjernet appsettings.

{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "MyAzureSqlConnectionString": "Server=tcp:<your-server-name>.database.windows.net,1433;Initial Catalog=<your-db-name>;Persist Security Info=False;User ID=<your-username>;Password=<your-password>;MultipleActiveResultSets=False;Encrypt=True;TrustServerCertificate=False;Connection Timeout=30;"
  }
}
